# Site Map

Last updated: 22 September 2026

## MVP structure

Use one focused homepage plus reusable case-study pages. This preserves the direct flow of the current one-page portfolio without forcing every project into a slide-like section.

```text
/
├── #impact
├── #experience
├── #case-studies
├── #about
├── #credentials
└── #contact

/case-studies/tara
/case-studies/un-humanitarian-automation
/case-studies/rag-virtual-patient

/resume.pdf
/404
```

## Page and section responsibilities

| Location | Purpose | Required content | Primary action |
|---|---|---|---|
| `/` hero | Establish relevance immediately | Positioning, Dublin location, one short introduction | View case studies |
| `#impact` | Prove value quickly | Three verified metrics with context | Open related case |
| `#experience` | Establish professional credibility | UN Thailand, UN Viet Nam, KBTG, AOT | Review experience |
| `#case-studies` | Show process and judgement | Three featured case cards; secondary work list | Read case study |
| `#about` | Explain motivation and perspective | UCD study, international experience, values | Connect on LinkedIn |
| `#credentials` | Add supporting evidence | Education, selected certifications, speaking/media | View credentials |
| `#contact` | Convert interest into contact | Email, LinkedIn, CV | Email Passapol |
| Case-study page | Demonstrate depth | Summary, context, role, challenge, approach, outcome, reflection, evidence | Contact or next case |
| `/resume.pdf` | Provide recruiter-ready detail | Current CV | Download |
| `/404` | Recover from broken links | Short message and home link | Return home |

## Navigation

Desktop and mobile navigation labels:

- Work
- Case Studies
- About
- Credentials
- Contact

The name/logo returns to the top. Keep the CV as a separate button. Active and focus states must not rely on colour alone.

```text
Positioning -> measurable proof -> relevant experience -> how the work was done
-> personal fit and credentials -> contact
```

## Excluded from the MVP

- Blog or news archive.
- Separate pages for every certificate.
- Search, accounts, comments, or a content-management system.
- A contact form; direct email and LinkedIn are sufficient.
